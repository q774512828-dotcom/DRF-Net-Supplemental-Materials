# Supplemental Materials for DRF-Net

This repository contains supplemental materials for the manuscript:

**DRF-Net: A Re-parameterized Feature Fusion Network with Multi-Scale Selective Kernel Attention for Dam Surface Defect Detection**

The supplemental materials include Figs. S1--S22, which provide additional qualitative detection results and visualization examples for the DSI-Data-set, the Damage Detection subset of DamSegment, and the Cracks Yolo Nas dataset.

These materials are provided to support the experimental analysis and visual comparison reported in the manuscript.
